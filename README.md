# CyrilPublicity

Public website for CyrilPublicity, a graphic design studio. Built with Next.js App Router.

The original static HTML is kept in `legacy/` for reference. Site content currently lives in `lib/` so an admin panel can replace it later.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve the production build
